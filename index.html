Assistente do alfabeto

Treina as letras sem movimento, uma de cada vez. A letra aparece sobre a câmera: faça o sinal e mantenha a mão à vista. Dura cerca de 3 minutos.

Limpar tudo (polegar para baixo, parado), depois Falar (3 toquinhos na boca) e Apagar (3 tapinhas para trás), os dois com movimento. Espaço continua sendo a mão aberta.

Reforço: mais casos de cada letra

Quanto mais jeitos diferentes de fazer a mesma letra, mais preciso fica. Cada rodada passa por todas as letras de novo (cerca de 2 minutos) pedindo uma variação. Faça 2 ou 3 rodadas e a rede treina sozinha no fim. Os exemplos novos se somam aos anteriores.

Como fazer o sinal

Desenho esquemático, só para orientar. Confira com um quadro de Libras ou com quem ensina. O sistema aprende o sinal que você fizer, então o importante é repetir sempre do mesmo jeito.

1. Ensinar uma letra

Escolha a letra, faça o sinal diante da câmera e aperte “Gravar”. Repita para cada letra. O ESPAÇO é o sinal combinado para separar palavras.

2. Treinar a rede neural

A rede começa sem saber nada, erra, ajusta os pesos e vai acertando. O gráfico mostra o erro caindo.

Grave pelo menos 2 letras (15 exemplos cada).

3. Letras com movimento experimental

Para sinais que se desenham no ar, como J e Z. Escolha a letra e grave 8 repetições: a cada sinal sonoro, faça o movimento completo. Depois treine os movimentos.

Grave pelo menos uma letra com movimento.

Cópia de segurança

Baixe os exemplos para um arquivo. Se o navegador apagar os dados, é só carregar de volta.

Soletrar

Faça o sinal e segure por um instante: o anel enche e a letra entra na palavra. Para repetir a mesma letra, tire a mão da câmera e coloque de novo.

Voz do computador

Para a voz mais natural, abra a página no Microsoft Edge e escolha uma voz “Natural” (Francisca, Antonio ou Thalita). No Chrome, a “Google português do Brasil” também é boa.

Gestos de comando: ESPAÇO mão aberta · APAGAR ⌫ 3 tapinhas para trás · LIMPAR ✕ polegar para baixo · FALAR ▶ 3 toquinhos na boca.

Treine a IA na aba “Aprender” primeiro.

Cuidado ao reconhecer

A letra só é aceita se a mão ficar firme por um instante. Assim, o formato “no meio do caminho” entre uma letra e outra não vira letra errada. Se estiver lento demais, use Rápido; se ainda errar, use Cuidadoso.

Modo cofre

Ative, defina a senha e soletre. Se acertar, o Arduino comemora.

Desafio dos Sinais

A tela mostra uma letra. Faça o sinal antes que o tempo (no telão de 9 a 0) acabe. Quanto mais rápido, mais pontos.
